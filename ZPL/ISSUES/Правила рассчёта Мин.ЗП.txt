Пример 10. Работа по совместительству 

Работник работает по внутреннему совместительству: 
1 ставка по основному месту (оклад 5500 грн) и 0,5 ставки по совместительству (оклад 5000 грн). 

В марте 2022 г. им была выполнена норма труда для 175 ч по основному месту 
и 79 ч по совместительству при месячной норме 175 часов для 40-часовой рабочей недели. 

При такой работе работник и как совместитель выполняет другую работу по отдельному 
трудовому договору в свободное от основной работы время. 
Следовательно, доплата до минимальной зарплаты определяется отдельно для каждого места работы. 

Начислено по основному месту работы: 5500 грн. 
Начислено за работу по совместительству: 5000/175×79= 2257,14 грн. 

Минимальная зарплата для работы по основному месту: 6500 грн. 
Минимальная зарплата для работы по совместительству: 6500/175×79= 2934,29 грн. 

Доплата до минималки по основному месту: 6500 - 5500 = 1000 грн. 
Доплата по работе по совместительству: 2934,29 – 2257,14 = 677,15 грн. 
Всего начислено работнику в марте 2022: (5500 + 1000) + (2257,14 + 677,15) = 6500 + 2934,29 = 9434,29 грн.
